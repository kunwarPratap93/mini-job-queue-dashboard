## Important Locations

- Backend source: `backend/src/`
- Frontend source: `frontend/src/`
- Local SQLite database: `backend/database.sqlite`
- Test SQLite database: `backend/test.sqlite`
- Backend database configuration: `backend/src/app.module.ts`
- Job entity definitions: `backend/src/jobs/entities/`
- Backend compiled output: `backend/dist/`
- Frontend compiled output: `frontend/dist/`

`node_modules/` contains installed third-party packages and is intentionally represented as a directory rather than expanded, because its contents are generated from the package lock files and are not application source files.
